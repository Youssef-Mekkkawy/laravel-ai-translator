# Contributing to Laravel AI Auto-Translator

Thank you for considering contributing to Laravel AI Auto-Translator! 🎉

## How to Contribute

### Reporting Bugs

If you find a bug, please open an issue with:
- Clear description of the bug
- Steps to reproduce
- Expected vs actual behavior
- Laravel version, PHP version
- Error messages or logs

### Suggesting Features

Feature requests are welcome! Please include:
- Use case: Why do you need this feature?
- Expected behavior: What should it do?
- Alternatives: Have you considered other approaches?

### Pull Requests

We love pull requests! Here's the workflow:

1. **Fork the repo** and create your branch from `main`
2. **Install dependencies**: `composer install`
3. **Make your changes**
4. **Add tests** for your changes
5. **Run tests**: `composer test`
6. **Format code**: `composer format`
7. **Run static analysis**: `composer analyse`
8. **Commit** with clear message
9. **Push** to your fork
10. **Submit pull request**

### Coding Standards

- Follow PSR-12 coding standards
- Write clear, descriptive variable/method names
- Add PHPDoc blocks for all classes and methods
- Keep methods focused and small
- Write tests for new features

### Testing

```bash
# Run tests
composer test

# Run tests with coverage
composer test-coverage

# Format code
composer format

# Run static analysis
composer analyse
```

### Commit Messages

Use clear, descriptive commit messages:

```
✅ Good:
- "Add DeepL translator integration"
- "Fix hash tracking for nested arrays"
- "Update documentation for backup system"

❌ Bad:
- "fix bug"
- "update stuff"
- "changes"
```

### Code of Conduct

- Be respectful and inclusive
- Focus on what's best for the community
- Show empathy towards other contributors
- Accept constructive criticism gracefully

## Development Setup

```bash
# Clone your fork
git clone https://github.com/YOUR_USERNAME/laravel-ai-translator.git
cd laravel-ai-translator

# Install dependencies
composer install

# Run tests
composer test
```
