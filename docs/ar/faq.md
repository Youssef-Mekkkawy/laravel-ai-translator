# الأسئلة الشائعة

## لا يتم ترجمة أي شيء — لماذا؟

**تحقق 1 — Ollama يعمل:**
```bash
curl http://localhost:11434/api/tags
```
إذا لم يكن هناك استجابة، ابدأ Ollama: `ollama serve`

**تحقق 2 — تتبع Hash:**
إذا ترجمت من قبل، يتم تخطي المفاتيح غير المتغيرة. أجبر على إعادة الترجمة:
```bash
php artisan lang:translate --force
```

---

## ما الفرق بين التبديل والإزالة في صفحة اللغات؟

- **مفتاح التبديل** — يعطل/يفعّل اللغة. تُحفظ ملفات الترجمة.
- **أيقونة المهملات** — يزيل اللغة نهائياً من الإعداد ويحذف جميع ملفات ترجمتها.

---

## ملفات PHP مقابل JSON — أيهما يستخدم تطبيقي؟

- **ملفات PHP** (`lang/ar/auth.php`) — للمفاتيح بالنقطة مثل `__('auth.login')`
- **ملفات JSON** (`lang/ar.json`) — للمفاتيح النصية الكاملة مثل `__('Login')`

تكتشف الحزمة التنسيق المناسب تلقائياً.

---

## جودة الترجمة رديئة — ماذا أفعل؟

1. **استخدم نموذجاً أفضل** — `aya-expanse:8b` يعطي نتائج أفضل بكثير
2. **أضف سياقاً** — في الإعدادات: `"هذا تطبيق تجارة إلكترونية. استخدم لغة رسمية."`
3. **اقفل الترجمات الجيدة** — عندما تصلح ترجمة يدوياً، اقفلها
