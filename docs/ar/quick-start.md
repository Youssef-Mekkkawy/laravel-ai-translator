# البدء السريع

ترجم تطبيق Laravel الخاص بك في 3 خطوات.

## الخطوة 1 — فحص Views

ابحث عن جميع مفاتيح الترجمة المستخدمة في تطبيقك:

```bash
php artisan lang:scan
```

## الخطوة 2 — الترجمة

ترجم جميع المفاتيح المفقودة إلى لغاتك المُعدَّة:

```bash
php artisan lang:translate
```

## الخطوة 3 — افتح لوحة التحكم

```
http://your-app.test/ai-translator
```

ستجد إحصائيات التغطية والتاريخ الحديث والإجراءات السريعة.
