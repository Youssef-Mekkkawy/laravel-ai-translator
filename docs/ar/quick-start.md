# البدء السريع

اجعل تطبيق لارافيل مترجمًا في 3 خطوات.

## الخطوة 1 — فحص الـ Views

ابحث عن كل مفاتيح الترجمة المستخدمة في تطبيقك:

```bash
php artisan lang:scan
```

يقوم هذا الأمر بفحص Blade views ومكونات Livewire وملفات Vue/React (حسب الحزمة التقنية المستخدمة) ويعرض عدد المفاتيح التي تم العثور عليها.

## الخطوة 2 — الترجمة

ترجم كل المفاتيح المفقودة إلى اللغات المُعدة لديك:

```bash
php artisan lang:translate
```

سيقوم الأمر بـ:
- عرض التكلفة المتوقعة (مجانية مع Ollama)
- طلب التأكيد
- ترجمة كل المفاتيح
- عرض ملخص لما تمت ترجمته

## الخطوة 3 — افتح لوحة التحكم

```
http://your-app.test/ai-translator
```

ستشاهد نسبة تغطية الترجمة، والسجل الأخير، والإجراءات السريعة.

## استخدام لوحة التحكم

بدلًا من CLI، يمكنك فعل كل شيء من لوحة التحكم:

1. اضغط **Scan** للبحث عن مفاتيح جديدة
2. اضغط **Translate** لبدء الترجمة
3. راقب شريط التقدم اللحظي
4. شاهد نسبة التغطية لكل لغة في الرسم البياني أدناه

## إضافة المزيد من اللغات

من صفحة Languages، اضغط **+ Add language** واختر من بين أكثر من 180 لغة. ستبدأ الحزمة بالترجمة إلى اللغة الجديدة في التشغيل التالي.
